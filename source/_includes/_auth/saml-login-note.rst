**Admin Panel Access with SAML Authentication**

After SAML authentication is enabled, login is handled by the configured
SAML Identity Provider for both the Webmail interface and the **Admin Panel**.
Therefore, the SAML login screen will also be presented when administrators
access the Admin Panel.

.. note:: **SAML authentication** settings apply to both the **User UI** and the **Admin Panel**. Enabling or disabling SAML authentication also enables or disables SAML authentication for the Admin Panel.
