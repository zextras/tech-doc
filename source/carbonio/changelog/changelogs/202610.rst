New and Updated Content

.. rubric:: 202610-2117 Updated SOAP API namespace syntax documentation

.. rubric:: 202610-2114 Updated Carbonio Backup item definition in documentation

Removed the expression for example and revised the definition of item within the Carbonio Backup architecture page. These changes improved the clarity and conciseness of the technical description for users.

Documented the SOAP endpoints for zimbraAccount, zimbraMail, and zimbraAdmin namespaces in the authentication guide. The update included endpoint URLs and clarified the relationship between namespaces and request submission points.


.. rubric:: 202610-2112 Updated Carbonio 26.9 changelog with CO-4322

Added the technical changes implemented in CO-4322 to the Carbonio 26.9 changelog. This ensured that the documentation accurately reflected all improvements included in the release.


.. rubric:: 202610-2105 Removed Advanced from Carbonio license notification example

Updated the Notifications documentation by removing the word Advanced from the Subject field example. This change ensured the documentation correctly reflected the official commercial product name Carbonio.


.. rubric:: 202610-2101 Moved metrics reference commands to new section

Relocated all metrics related CLI commands from the Core section to a newly created Metrics section in the documentation. This change improved the organization of the CLI reference by providing a dedicated space for metrics monitoring commands.


.. rubric:: 202610-2095 Updated Core CLI documentation removing bucket commands

Removed bucket management commands from the Carbonio Core CLI documentation pages. The updated documentation no longer includes commands such as testS3Connection and various doCreateBucket options.

.. rubric:: 202610-2088 Updated Carbonio Powerstore CLI storage documentation

Removed obsolete storage types and added new S3 connector commands to the Powerstore CLI documentation page. These changes ensured the documentation accurately reflected the simplified storage support introduced in Carbonio 26.9.


.. rubric:: 202610-2059 Updated mobile device sync CLI documentation

Clarified that account identifiers for device sync commands accepted both UUID and email address. Added explicit examples and parameter descriptions for the suspend and resume sync operations.


.. rubric:: 202610-2057 Updated Infrastructure SSL documentation with file ownership

Added instructions to set the zextras user ownership for certificate files in the temporary directory. This change ensured that commercial certificate installations no longer failed due to permission issues.


.. rubric:: 202610-2056 Updated Carbonio upgrade documentation sections

Removed outdated Carbonio Files cache troubleshooting and post-upgrade quota configuration sections from the documentation. Added new information to the Unified Quota model section to ensure accurate migration guidance.


.. rubric:: 202610-2051 Added Greek to community supported languages

Updated the available languages section in the Carbonio documentation to include Greek as a community supported language. This change ensured that the Greek localization was listed consistently with other community supported languages for users.


.. rubric:: 202610-2042 Updated API pages for 26.6.0 release

Updated the Carbonio API Overview to ensure all referenced APIs use the current versions and follow the unified REST API deployment flow.

Removed the Ansible upgrade documentation for older Carbonio versions from the public admin guide. This change ensured that the documentation aligned with the official support policy for only the three latest versions.


.. rubric:: 202610-2016 Updated public changelog for Carbonio 26.9

Documented the main user and administrator facing changes introduced in the Carbonio 26.9 release. Organized the updates by functional area to provide a concise overview of relevant improvements and new features.
